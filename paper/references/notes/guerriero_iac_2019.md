# Adoption, Support, and Challenges of Infrastructure-as-Code: Insights from Industry

**Authors:** Guerriero, Michele; Garriga, Martin; Tamburri, Damian A.; Palomba, Fabio; Lago, Patricia
**Year:** 2019
**Source:** IEEE International Conference on Software Maintenance and Evolution (ICSME), pp. 580-589
**DOI:** 10.1109/ICSME.2019.00092

## Summary

Empirical study based on interviews with 44 practitioners from 11 companies investigating IaC adoption, tool support, and challenges. Identifies configuration drift, testing complexity, and lack of standardization as key challenges. Finds that IaC is widely adopted but maturity levels vary significantly across organizations.

## Key Findings

- IaC adoption is driven by repeatability, version control, and automation benefits
- Configuration drift remains a major challenge despite IaC tooling
- Testing IaC configurations is harder than testing application code
- Tool fragmentation: Terraform, Ansible, Puppet, Chef, CloudFormation all coexist
- Provisioning (creating infrastructure) vs configuration management (managing software) are distinct concerns
