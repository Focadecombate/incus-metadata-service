# The NIST Definition of Cloud Computing

**Authors:** Mell, Peter; Grance, Timothy
**Year:** 2011
**Source:** NIST Special Publication 800-145
**Publisher:** National Institute of Standards and Technology

## Summary

The authoritative definition of cloud computing by NIST, establishing the five essential characteristics (on-demand self-service, broad network access, resource pooling, rapid elasticity, measured service), three service models (SaaS, PaaS, IaaS), and four deployment models (private, community, public, hybrid). This 7-page document is the most cited reference in cloud computing literature.

## Key Findings

- Cloud computing = on-demand network access to a shared pool of configurable computing resources
- IaaS provides processing, storage, networks — the model your Incus environment operates in
- Private cloud: infrastructure provisioned for exclusive use by a single organization
- Self-service and automation are essential characteristics — metadata services enable this

## Pertinent Information for TCC

- **Foundational reference** for defining cloud computing in academic context
- Private cloud model is the deployment context for your service (homelab, edge, small-scale)
