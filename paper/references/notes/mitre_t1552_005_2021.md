# MITRE ATT&CK T1552.005 — Unsecured Credentials: Cloud Instance Metadata API

**Author:** MITRE Corporation
**Year:** 2021
**Source:** MITRE ATT&CK Framework
**URL:** https://attack.mitre.org/techniques/T1552/005/

## Summary

MITRE ATT&CK technique entry documenting the exploitation of cloud instance metadata APIs for credential theft. Categorizes this as a sub-technique of T1552 (Unsecured Credentials) under the Credential Access tactic. Lists known threat groups, software, and mitigations.

## Key Findings

- Classified under Credential Access tactic — adversaries access metadata APIs to steal credentials
- Attack vector: HTTP requests to `169.254.169.254` from within a compromised instance
- Targets: IAM credentials, SSH keys, instance identity tokens, user-data (may contain secrets)
- Mitigations: restrict network access to metadata service, use IMDSv2, avoid storing secrets in user-data
- Used by multiple APT groups and documented in real-world breaches (Capital One)

## Pertinent Information for TCC

- Cited in the security subsection of related work and in the conclusion
- Provides authoritative taxonomy for the metadata service attack vector
- Your service doesn't serve IAM credentials (unlike AWS IMDS), reducing the attack surface
- Still relevant: SSH keys and user-data could contain sensitive information
